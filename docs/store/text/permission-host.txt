api.npmjs.org: daily download counts for the package being viewed and for the reference packages; this is the data the correction is computed from. registry.npmjs.org: the package's maintainers and the maintainer's other packages for the "By author" list. Requests contain package names only. www.npmjs.com: the content script that renders the panel on package pages; registered for the whole site because npmjs.com is a single-page app (navigating from search to a package does not reload the page). It only adds its own panel and does not read or change the page.
